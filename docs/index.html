Reference kit · runs on a laptop · mock server

Know what each tenant costs, and gate every canary before it ships.

A reference kit for shipping and observing AI inference services: per-tenant cost attribution and quotas, a multi-tenant OpenTelemetry Collector, and a canary gate that decides promote or rollback.

Built for platform and SRE engineers who run, or are about to run, shared LLM inference and want cost, limits and rollout checks worked out before any GPUs are involved.

How it fits together

From request to promote or rollback

Three paths share one tenant identity: the x-tenant-id header at the edge, the tenant.id resource attribute in OpenTelemetry, and the tenant label in Prometheus. Moving dots show direction only.

1Request path

  1. ClientSends the x-tenant-id header with each request.
  2. EnvoyRequires the tenant header (otherwise 401), applies per-tenant local rate limits, keeps streaming alive.
  3. Inference servervLLM in deploy/, the mock server locally. Emits /metrics and OTLP spans.

2Telemetry path

  1. Inference serverTokens, GPU seconds, cost and latency, labeled by tenant.
  2. OTel CollectorTenant stamped: copies x-tenant-id to tenant.id, defaults to unknown.
  3. PrometheusScrapes the collector's exporter and the server's /metrics.
  4. Grafana and alertsDashboard JSON and 8 alert rules in deploy/.

3Verification path

  1. Prometheus metricsp95 latency, error rate, cost per 1k tokens.
  2. Eval scoreRead from a JSON file. No eval harness is included.
  3. Canary gateaidelivery gate in CI (exit 0 promotes, 1 rolls back), or an Argo Rollouts AnalysisTemplate. Missing data fails closed.
  4. PROMOTEROLLBACK

The Argo Rollout and AnalysisTemplate manifests passed kubeconform but were never applied to a cluster. See the validation table below.

Browser simulation of the repo's rules, not the Python program. Presets use the values the Python gate computes from tests/fixtures/. A check passes when its value is at or inside the limit. What is in the repo

Features

01

Multi-tenant OTel Collector

Copies the x-tenant-id header onto every span, metric and log as tenant.id. Anything without a tenant is stamped unknown so it stays visible. Per-tenant span metrics via the spanmetrics connector.

otel/collector.yaml
02

Per-tenant cost attribution

Tokens and GPU seconds priced from a rate card, exported as aidelivery_cost_usd_total by tenant and model. Rate card prices are placeholders.

src/aidelivery/cost.py, config/ratecard.json
03

Quotas and budgets

Thread-safe token bucket per tenant (tested with 200 concurrent callers) and per-tenant budgets. A spent budget makes the mock server answer 429. Envoy adds a coarse per-instance limit in front.

src/aidelivery/quota.py, deploy/envoy/envoy.yaml
04

Canary gate

Six checks: request volume, p95 latency, error rate, cost per 1k tokens, eval score, hallucination rate. Exit 0 promotes, 1 rolls back, 2 means bad input. Missing data fails closed.

src/aidelivery/gate.py
05

Mock OpenAI-compatible server

Serves /v1/chat/completions with SSE streaming, 429s and Prometheus metrics, plus OTLP spans. It runs no model. Partial streams are billed for tokens already sent.

src/aidelivery/mock_server.py
06

Deploy configs

Prometheus alert rules and scrape config, a Grafana dashboard, an Envoy config, a vLLM Helm chart, and an Argo Rollout with an AnalysisTemplate and Argo CD Application.

deploy/

Quick start

Run it on a laptop

Copied from the README. They were run on macOS with Docker Desktop, Python 3.14 locally and 3.12 in CI.

1. Install and test
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[server,dev]"
pytest -q
35 passed, 1 warning in 0.41s
2. Canary gate against the mock server (half of requests fail)
scripts/canary_smoke.sh 0.5

Exit code 0 means promote, 1 means rollback. scripts/canary_smoke.sh 0 ends in DECISION: PROMOTE. The eval score comes from a fixture JSON file, not from a real eval run.

3. Local stack: mock server, collector, Prometheus, Grafana
docker compose up -d --build
curl -s localhost:8000/v1/chat/completions -H 'X-Tenant-ID: acme' -H 'content-type: application/json' \
  -d '{"model":"mock-model","messages":[{"role":"user","content":"hello"}]}'
{"id":"chatcmpl-2c7a81926f9c","object":"chat.completion","model":"mock-model","choices":[{"index":0,"message":{"role":"assistant","content":"This is a mock completion from the aidelivery mock server. No model is running."},"finish_reason":"stop"}],"usage":{"prompt_tokens":1,"completion_tokens":14,"total_tokens":15}}
4. Query per-tenant requests in Prometheus
curl -s localhost:9090/api/v1/query --data-urlencode 'query=sum by (tenant) (aidelivery_requests_total)'

Grafana is at http://localhost:3000 (anonymous viewer). Panels that use DCGM metric names stay empty locally because there is no GPU exporter.
